WHERE DO WE START?
Start by building a content repository of AI enterprise GTM articles, video interviews, and playbooks.
1. BUILD + SEED
Build the Workshop website (like this one!). Migrate and categorize existing content within the new website. Provide an access point for users to sign up for the Enterprise Weekly newsletter.
2. CAPTURE
Create new content, beginning with the first five case studies to generate practical insights via articles and playbooks, before layering in video interviews with enterprise leaders.
3. FORMAT
All content should be made accessible as text and audio, catering to user preference by using text-to-speech and speech-to-text models.
4. SCHEDULE
Define the operational system to scale and automate content creation, and build a content release calendar.

THE MENTORSHIP PROGRAM
BUILDING PARTNERSHIPS
Build a mentorship ecosystem and match Work-Bench founders with relevant enterprise leaders.
MILESTONE 1: PROBLEM + ADVICE
Coordinate the first founder and mentor meeting at the Work-Bench office. Let the mentor listen, pressure-test, and advise the founder.
MILESTONE 2: CHECK-IN
Bring the two back together after 90 days. Let them discuss what's working, what's stalled, and what was surfaced. The mentor can help open doors if useful.
MILESTONE 3: RESULTS + TAKEAWAYS
On day 180, bring back the duo for a final time for an honest retro. Talk about the wins, losses, and transferrable lessons other founders can use.
